# Project Overview

BCAHub is a free academic platform developed to help **Bachelor of Computer Applications (BCA)** students access study materials quickly and efficiently.

Instead of searching across multiple websites and scattered Google Drive links, students can find everything in one organized platform. Resources are grouped semester-wise and category-wise, making it easier to locate the required material.

The platform focuses on providing a clean experience without mandatory registration or unnecessary distractions.

## Key Highlights

- Semester-wise resource organization
- Notes and study materials
- Assignments
- Previous year question papers
- Important questions
- Lab records
- Syllabus
- PDF resources
- Fast search and filtering
- Deep-link support for individual resources
- Copy Resource Link functionality
- Mobile-friendly responsive interface
- SEO optimized static website
- Hosted on GitHub Pages
- Free to use

# Features

## Academic Resources

BCAHub organizes study materials into multiple academic categories.

- Notes & Materials
- Assignments
- Important Questions
- Previous Question Papers
- Lab Records
- PDF Resources
- Semester Syllabus

Resources are grouped by semester, allowing students to browse only the materials relevant to their course.

---

## Semester-wise Organization

Resources are available semester-wise from:

- Semester I
- Semester II
- Semester III
- Semester IV
- Semester V
- Semester VI

Users can also browse resources from all semesters together.

---

## Smart Resource Filtering

Students can quickly locate resources using built-in filters.

Available filters include:

- Semester
- Resource Category

This makes finding documents much faster than manually browsing folders.

---

## Deep-Link Support

Every supported resource includes a unique Resource Reference Link.

These links allow:

- Direct sharing of individual resources
- Opening a specific resource immediately
- Easy bookmarking
- Reliable referencing across platforms

---

## Copy Resource Link

Each resource includes a **Copy Resource Link** button.

With one click users can copy a shareable link pointing directly to that resource.

This helps students, teachers, and educational websites reference original BCAHub resources instead of re-uploading duplicate copies.

---

## Content Galaxy

Content Galaxy is BCAHub's article section.

It contains educational content covering topics such as:

- Space
- Interesting Facts

Students can browse articles using category filters and search.

# Project Structure

The project follows a simple multi-page structure, making it easy to maintain and extend.

```text
bcahub/
├── about/              # About BCAHub
├── contact/            # Contact page
├── content/            # Content Galaxy
├── forms/              # Request & feedback forms
├── help/               # Help & FAQs
├── pictures/           # Images and icons
├── privacy/            # Privacy Policy
├── resources/          # Academic resources
├── terms/              # Terms of Use
├── videos/             # Demo videos
│
├── index.html          # Home page
├── styles.css          # Global styles
├── script.js           # Home page scripts
├── loader.css          # Loader styles
├── loader.js           # Loader script
├── robots.txt
├── sitemap.xml
└── README.md
```
