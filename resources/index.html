Report or Suggest

All Forms

If you notice anything that needs fixing or updating, feel free to reach out! You can contact us for:

  • Broken Links – Found a link that doesn’t work? Let us know so we can fix it.
  • Adding Resources – Have useful content you'd like to share? We’re happy to include it with proper credit. If ypu want to send any file to me please send through e-mail
  • Incorrect Info or Spelling Errors – Help us keep everything accurate and typo free.
  • Subject Updates – Want to rename, change, or remove a subject? Tell us!
  • Syllabus Changes – If the syllabus has been updated, we’d love to know so we can keep our resources current.
